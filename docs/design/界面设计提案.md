## 原有功能对应

| 原有功能 | 设计中的保留方式 |
| --- | --- |
| 月份切换、返回今天、日期计划数 | 首页月历工具栏与日期标记 |
| 按日查看、删除计划明细 | A 版右侧日期明细入口；B 版当日概览与明细表 |
| 保电、风险预警、自定义排班 | 任务类型选择，保留各类独立字段及级别配置 |
| 日期范围、通知单号、设备粘贴、站点识别 | 任务填写面板 |
| 自定义项目名称、单日日期、巡视和测温次数 | 关键流程说明中保留字段要求，选中类型后切换对应表单 |
| 草稿编辑、规则锁定、返回表单、确认生效 | 核对面板，保留巡视方式和次数调整要求 |
| 任务记录、查看、编辑、删除、按任务导出 | A 版页头入口；B 版侧边导航；关键流程说明列出完整操作 |
| 跨月范围导出 Excel | 导出巡视安排入口，沿用原有日期范围选择和文件输出 |
| 导出系统数据、导入预览、合并新增、覆盖 | A 版底部备份区域；B 版侧栏底部数据管理入口 |
| 替代巡视规则、特殊巡视规则、巡视替代列表 | A 版底部规则区；B 版侧边导航 |
